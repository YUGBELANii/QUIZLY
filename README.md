# 🧠 Quizify

An AI-powered quiz generation platform that converts PDFs into interactive quizzes and learning experiences.

## 📖 About

Quizify helps students and learners quickly transform study material into quizzes. Upload a PDF, generate questions, and test your understanding instantly.

## ✨ Features

- PDF Upload
- AI Question Generation
- Multiple Choice Questions
- Instant Scoring
- Quiz Results & Analytics
- Mobile-Friendly Interface
- Learning Assessment

## 🛠️ Tech Stack

### Frontend
- React Native
- Expo
- TypeScript

### Backend
- Python
- FastAPI

### AI & Processing
- PDF Text Extraction
- Quiz Generation Engine
